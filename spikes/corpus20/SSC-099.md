Date: 2026-10-10. Status: **Claude Code and Codex recorded, both live on preview. The audit rows' seq numbers and client ids are not read yet; Cursor was not run.**

This backs the landing page's `tools` claim (`landing/CLAIMS.md`) for Claude Code and Codex (GA-9.8).

How it differs from SSC-003 (`RESULTS.md`): these two runs went through SSC itself, the remote MCP
server `https://api.delimitus.com/mcp`, cell 2 (`proofcell02`), org Test Customer 2, not the
spike's local Docker and throwaway project. The tool both wrote the app and deployed it. No app
source is in this repo.

## Method

Each tool was run headless with one prompt, identical apart from the slug and the folder wording.
`ssc init` had been run in the folder first. Neither tool got a follow-up prompt.

The Claude Code prompt, in full:

> Build a small internal web app in the folder app-claude: a team lunch-order board (Python or Node, your choice) where people add an order and see today's list, kept in memory. It must run on Delimitus SSC: follow app-claude/AGENTS.md and call get_platform_requirements first. Then create an SSC app called ga98-claude for me (yes, I am asking for it and that is the slug) and deploy that folder to its preview with the ssc tools, following the deploy tool's `next` steps until the stage is `live`. Check get_status and get_logs and tell me the preview address, the app id and the release.

- Claude Code: `claude -p`, `acceptEdits`, tools Read, Write, Edit, Glob, Grep, Bash and the ssc
  MCP tools.
- Codex: `codex exec --skip-git-repo-check -s workspace-write -c sandbox_workspace_write.network_access=true --json`.

## Findings

1. The agent pack names helper packages that are not published
   (`packages/ssc_cli/src/ssc_cli/agentpack/content.py`, lines 182 to 226: the reconnect helpers
   at 182 to 184, the identity helpers at 198 to 200, the files helpers at 225 to 226).
2. The signed upload URL that `deploy` returns lands in the agent's transcript. It expires in
   600 s (`packages/ssc_control/src/ssc_control/api/mcp/tools.py:477`).
3. The starter `.sscignore` does not exclude `AGENTS.md`, `.mcp.json`, `.claude/` or `.cursor/`,
   so they ship in the bundle.
4. One 20 s timeout, not reproduced, on the first unauthenticated GET to the `ga98-claude` preview
   at about 05:01:10Z.
