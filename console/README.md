# console

The SSC admin console (SSC-057), decision 018. React 19, Vite 8, TanStack Router (file routes) and
TanStack Query, with an API client generated from `docs/api/openapi.json`. Node 22.22.2+, 24.15+
or 26+ (jsdom's range); CI uses Node 24.

| Path | What |
|---|---|
| `src/api/` | `schema.d.ts` (generated, committed), `client.ts` (bearer token, `Idempotency-Key` on writes, problems become `ApiProblem`), `grants.ts` (sharing changes with `If-Match` and the 412 retry). |
| `src/tokens/` | Colour and type tokens adapted from the Delimitus UI tokens; `tokens.css` is generated from them. Components use only `var(--ssc-*)`. |
| `src/auth/` | Session (token in memory, optional copy in `sessionStorage`) and the dev token login. |
| `src/routes/` | `/login`, `/` (inventory), `/apps/$appId` (environments and who has access). `src/routeTree.gen.ts` is generated by the router plugin and committed. |
| `src/components/` | Button, Badge, Table, Dialog, ConfirmAction (type the slug to confirm), ProblemNotice. |
| `test/` | Vitest: tokens and contrast, the client, the screens against a fake API, and the dev login's absence from production builds. |
| `e2e/` | Playwright smoke test against Postgres and the real API in Docker. |

## Commands

```
npm ci
npm run dev          # Vite on :5173; /v1 is proxied to SSC_API_URL (default http://127.0.0.1:8000)
npm run typecheck
npm test
npm run build        # production build, without the dev login
npm run gen:api      # after docs/api/openapi.json changes; CI fails on a stale client
npm run gen:tokens   # after changing src/tokens/*.ts; CI fails on a stale tokens.css
npm run e2e          # needs Docker; see below
```

## Against a local API

```
uv run python tools/dev_stack.py up --dsn postgresql://postgres@127.0.0.1:5432/postgres
uv run python tools/dev_stack.py serve --port 8000
uv run python tools/dev_stack.py token          # paste this into the console's sign-in page
SSC_API_URL=http://127.0.0.1:8000 npm run dev
```

The token sign-in page exists only in `npm run dev` and in builds made with
`VITE_SSC_DEV_LOGIN=1`. A normal production build has no way to sign in until the SSC auth host
exists (decision 018); `test/devlogin-absent.test.ts` checks the build output.

## End-to-end test

`npm run e2e` runs `e2e/run.mjs`: it starts `e2e/compose.yaml` (Postgres 18 and the API built
from `e2e/api.Dockerfile`) under a random project name and host port, mints a token with
`dev_stack.py token`, builds the console with the dev login, runs Playwright, and removes the
containers. Install the browser once into `node_modules`:

```
PLAYWRIGHT_BROWSERS_PATH=0 npx playwright install chromium
```

## Dependencies

Exact versions only. `.npmrc` sets `before=` to a date at least 7 days back, so npm resolves
nothing newer; move it forward when upgrading. CI also runs `tools/npm_lock_age_check.py` on
`package-lock.json`. Never commit `node_modules`.
