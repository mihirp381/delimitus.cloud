Security

Agents move fast. Your policies still win.

Five boundaries hold for every app, whoever deployed it.

Identity boundary

Behind company login

Every app sits behind your company login. There are no public links.

Data boundary

Only approved data

An app gets only the company data connections IT approved, and reads them read-only.

Network boundary

Only allowed hosts

Apps reach only the internet hosts IT allows, and never each other.

Secret boundary

No credential for the agent

The agent never needs the key. Secrets are stored for the app and never shown again, to people or agents.

Deployment boundary

Production on your terms

Production can require an approval, and an agent can never approve a request.

Giving an agent permission to deploy doesn’t give it permission to get around IT.

Questions

What does it cost?

Pricing is agreed with each pilot. The cost section shows what doing it yourself costs.

Is Delimitus a coding agent?

No. Delimitus isn’t another coding agent. It’s where coding agents deploy company software.

Which tools can I build with?

Claude Code, Codex and Cursor deploy directly: the agent calls Delimitus from the editor. Lovable and Replit apps deploy through GitHub. Python and Node apps.

Can an agent get around IT?

No. An agent can deploy to preview and ask for access or data. Only an admin can approve, and an agent can never approve a request.

Where does it run?

On Google Cloud in the US, with each company in a cloud account of its own.

Who can open my app?

Only people signed in with your company login, and only the ones you shared it with: a person, a group, or the whole company.

Can an app be public?

No. Every request needs a company login.

What happens to my code and data?

Your app runs in your company’s own cloud account. It reads company databases read-only and reaches the internet only where IT allowed it. Secrets are never shown again, to people or to coding agents.
